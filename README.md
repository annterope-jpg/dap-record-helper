# DAP Record Helper

精神科・心理臨床での面接記録を、DAP（Data / Assessment / Plan）形式で整理するための**単一HTMLファイルの記録支援ツール**です。

## 特徴

- ブラウザ上だけで動作する単一HTML
- 自動保存なし・外部通信なし・AI接続なし
- 通常DAP／初回・包括的アセスメント／複雑ケースDAP
- 必要時のみ、トラウマ・解離、高校生・学生、家族・夫婦同席、安全性・リスクなどの補助欄を追加
- 完成記録を電子カルテへコピーしやすい形式で出力
- 相談用要約と記録ガイドを搭載

## 使い方

1. `index.html` または `versions/` 内の利用したい版をダウンロードします。
2. HTMLファイルをブラウザで開きます。
3. 面接内容を必要な欄だけ入力し、右側の完成記録を確認して電子カルテ等へコピーします。

> **重要**：このツール自体は入力内容を保存・外部送信しませんが、使用する端末・ブラウザ・電子カルテ側の運用や組織の規程は別途確認してください。氏名、患者ID、生年月日などの直接識別情報は入力しない運用を推奨します。

## バージョン公開方針

このリポジトリでは、開発過程を追えるように各版を `versions/` に残します。`index.html` はその時点の最新公開版です。

- **v4** — 初回公開版（2026-09-04）
- v5以降 — 2026-09-05から毎日 06:30（日本時間）に順次公開予定

変更内容は [CHANGELOG.md](CHANGELOG.md) と `releases/` 内の各版ノートに記録します。

## 注意事項

- 本ツールは診断、治療判断、リスク判定を自動化するものではありません。
- 入力した事実や臨床判断を整理する補助ツールです。
- 医療機関・所属組織の記録基準、個人情報保護方針、関連法令を優先してください。
- 公開されているサンプル文は説明用の架空例です。
