# PROJECT_CONTEXT.md — 長期文脈

## プロジェクト
DAP Record Helper

## 目的
精神科・心理臨床での面接記録を、DAP（Data / Assessment / Plan）形式を中心に整理し、電子カルテへ移しやすくする単一HTMLの記録支援ツール。

## 主な利用場面
- 成人中心の心理カウンセリング記録
- 初回・包括的アセスメント
- 複雑ケース
- 必要時のみトラウマ・解離、学生、家族・夫婦同席、安全性・リスク等の補助欄

## 重要な設計原則
- ブラウザ上だけで動作する。
- 自動保存・外部通信・AI接続を基本仕様にしない。
- DAPを中心に、観察事実・本人報告・臨床判断・計画を整理しやすくする。
- 完成記録を電子カルテへコピーしやすくする。
- 診断、治療判断、リスク判定を自動化しない。
- 既存の公開版・過去版・CHANGELOGとの整合性を保つ。

## 変更してはいけないもの
- 入力内容を無断で保存・外部送信する機能の追加。
- 氏名、患者ID、生年月日など直接識別情報の入力を前提にする設計。
- 臨床判断をAIやルールで自動決定する方向への変更。
- 既存の公開版を理由なく上書きして履歴を失うこと。

## 技術構成
- 単一HTMLを中心としたローカル実行
- `index.html` が最新公開版
- `versions/` に過去版を保持
- `CHANGELOG.md` と `releases/` で変更履歴を管理

## 安全・プライバシー
- このGitHubの共通知識ファイルに実症例・患者情報を書かない。
- 公開リポジトリのため、未公開の業務情報・内部運用情報も記載しない。
