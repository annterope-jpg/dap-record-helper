# v8 — DAP記録ガイドと品質チェックを拡充

公開予定日: 2026-09-08

入力しやすさだけでなく、「完成した記録が臨床記録として適切か」を自分で点検しやすくするため、使い方・記録ガイドを大幅に拡充しました。

## 変更点

- DAPの背景とD / A / Pそれぞれの役割を整理
- 記録を精査するための視点を追加
- 良い書き方と、修正が必要な書き方の比較例を追加
- D→A→Pのつながりや、事実と推測の区別を確認する品質チェックを追加
- 冒頭に視覚的な要点表示を置き、長い説明を読む前にポイントを確認できる構成へ変更

ガイドは、ユーザーが提供した『Note Designer』の内容を参考にしつつ、公開部分では書籍本文を転載せず、原則を要約・再構成し、例文は架空の独自例として作成しています。
